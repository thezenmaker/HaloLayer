# HaloLayer Privacy

HaloLayer is a local macOS utility. It does not require an account and does not transmit file names, file contents, folder paths, file metadata, or usage data to ZenMaker or third parties. File metadata is processed locally on the user's device.

## Permissions

HaloLayer uses:

- **Accessibility** to locate visible items in Finder Icon View and position overlays.
- **Finder automation** to identify the active folder and confirm its view mode.
- **Local filesystem access** to calculate file and folder sizes, media dimensions, and immediate folder-item counts.

These permissions are used only for the app's Finder display features. HaloLayer does not include analytics, crash reporting, remote update checks, or automatic downloads.

The HaloLayer source code and downloads are provided through GitHub. When following links to GitHub, [GitHub's Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement) applies.

## Changes to this statement

This statement must be updated before any future release adds crash reporting, update checks, analytics, automatic downloads, or another form of network data processing.
