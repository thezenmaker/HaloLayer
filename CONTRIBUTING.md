# Contributing to HaloLayer

Thanks for helping make Finder metadata calmer and clearer.

1. Open an issue before starting a large behavioral or architectural change.
2. Create a focused branch and keep unrelated edits out of the pull request.
3. Run `swift test` and the relevant checks in `MANUAL_TESTS.md`.
4. Explain the macOS and Finder versions used for manual verification.

Please never include personal file paths, filenames, screenshots, signing credentials, or other private data in issues and logs.
