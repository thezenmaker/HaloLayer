# Security

HaloLayer reads local Finder geometry and file metadata. It does not send this data over the network.

Please report security issues privately through GitHub's security advisory feature rather than opening a public issue. If that is unavailable, contact [hello@zenmaker.io](mailto:hello@zenmaker.io). Include the affected version and minimal reproduction details, but do not attach personal filenames or directory listings.

Unsigned preview downloads should only be obtained from this repository's Releases page. Never disable Gatekeeper globally to run HaloLayer.
